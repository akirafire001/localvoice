# S1：旅の手帖 — 実装した素材と画面

2026-10-10。選択されたS1のアイコンと挿絵をアプリに反映しました。[反映後の画面プレビュー](index.html)で確認できます。

## 素材

- 既存候補をもとにしたアイコン42点と、追加アイコン24点。個別の256×256px透過PNG。
- 既存候補をもとにした挿絵6点と、追加の挿絵4点。個別の640×480px透過PNG。
- 既に採用したアプリアイコンをログイン・ホームのブランド表示にも使用。
- 組み込み画像生成でS1を参照し、番号・罫線のない透過アトラスを作成しました。原本はこのフォルダーの4枚のPNG。全プロンプトと配置順序は [manifest.json](manifest.json)、切り出し記録は [exports.json](exports.json) です。
- [アイコン一覧](qa/icons-export-preview.png) / [挿絵一覧](qa/illustrations-export-preview.png)。

追加アイコンは言語、声、速度、頻度、説明、意外な話題、GPSの探索・オフ・許可なし、表示／非表示、メール、編集、ログアウト、削除、出典、各種操作など。追加挿絵は「メール確認待ち」「位置情報の許可」「パスワード再設定」「移動記録のない地図」です。

## 配置

| 画面 | 主な反映 |
| --- | --- |
| ログイン・登録 | ブランド表示、導入風景、アカウント・鍵・メール・目のアイコン |
| ホーム | ガイド開始の挿絵、目的5種・移動手段8種、設定・アカウント・履歴・地図 |
| ガイド | 9分類、読み上げ・停止・詳しく・次の話・関連・十分・評価、GPS・オフラインの状態、同行者 |
| 設定 | 言語・頻度・説明・意外な話題、9分類の重み、声・速度・端末読み上げ |
| 履歴 | 旅行目的・状態・話題分類、空の履歴やガイドのない旅行 |
| 地図 | 現在地・全体表示、移動記録のない状態 |
| アカウント・認証 | 編集・鍵・メール・ログアウト・削除、確認済みのメールと確認待ちを別の挿絵で表示 |

以前の画面案の下部タブは追加せず、現在のホームと画面遷移に合わせています。地図は引き続きMapLibreの実データです。Google・Appleの認証表示は既存のものを使用しています。

## 保存先と再書き出し

アプリが使用するPNG：
[app/assets/s1](../../../../app/assets/s1)、
[app/assets/branding](../../../../app/assets/branding)。

共通の描画と用途の対応：

テーマ：
[ui_theme.dart](../../../../app/lib/ui_theme.dart)。

PillowとNumPyを導入したPython環境で、リポジトリのルートから実行します。

```powershell
python tools/export_s1_assets.py
```

生成したPNGのアルファを維持し、絵の間の空白で切り出してサイズを揃えます。RGBA、透明な四隅、内部の切り出し境界で絵が欠けていないことを検証します。アプリの背景色に合成したプレビューも生成します。見た目のデザインをコードで描き直していません。
