## 現在のアプリとの対応

確認したコードの版：`3290f2b5a3b516da20d9b3c7d039b6a9d119854b`。

- ホーム：目的5種類（旅行・散歩・出張・通勤通学・その他）と移動手段8種類。地図・履歴へはホームから移動、設定とアカウントはAppBarから開く構成。
- ガイド：読み上げ／停止、詳しく、次の話、関連する話、この話題はもう十分、4種類の評価。現在の読み上げ操作に合わせて再生／停止を描いています。
- ガイド内の操作：同行者、移動手段変更、地図、一時指示の送信、30分静かにする操作。状態表示は測位・位置精度・オフラインなど。
- 設定と話題：歴史・建築・自然・食・文化・暮らし・産業・季節・実用の9分類。以前の画面案の5分類から、現行コードに合わせて候補を増やしています。
- 履歴：旅行一覧と旅行詳細。旅行がない／まだガイドがない状態に挿絵を置く案。
- 認証：ログイン、登録、パスワード再設定、メール確認、アカウント管理に対応。

## 挿絵の番号

## この段階の扱い

このフォルダーのPNGは比較時の一覧画像です。S1はその後、透過PNGへの生成・個別の切り出し・画面への組み込みを行いました。実装した素材と検証記録は [S1実装フォルダー](../../asset-production/s1/README.md) にあります。S2・S3は比較案として残しています。

地図データを装飾画像で置き換える提案ではありません。風景は架空の土地の導入イラストで、オフライン挿絵は端末に記録する既存動作の説明用です。Google・Appleの認証ロゴはこの候補セットの対象に含めていません。
